# 康源智慧人资平台 UI 操作手册

> 面向 **HR 操作员 / 高管 / 普通员工** 三类用户。看完本文 5 分钟即可上手。
> 集团：陕西省康源投资集团有限公司 ｜ 主色：康源橙 ｜ 形态：网页 H5，可嵌入钉钉容器

---

## 30 秒快速上手

1. 浏览器打开部署地址（形如 `https://xxx.vercel.app`）。
2. 在登录页选择身份并点击 `进入平台`。
3. 系统按角色自动跳转：员工到 `/self`、HR 到 `/hr/employees`、高管到 `/dashboard/overview`。
4. 左侧菜单点哪进哪，右上角头像可退出。

> 生产环境嵌入钉钉时自动免登，无需手动登录。

## 第二部分：员工自助操作

### 2.1 员工自助首页 `/self`

**页面是什么**：个人工作台，一屏看到本月工资概览、4 个快捷入口、待办提醒。

**怎么操作**：
1. 登录后默认进入，或点左侧菜单 `我的首页`。
2. 点顶部 4 张快捷卡片之一即可跳转：`我的工资单` / `年假余额` / `调休余额` / `考勤记录`。
3. 在「当月工资概览」卡片点 `查看工资单明细` 进入工资单。
4. 在「待办提醒」列表点 `去确认` / `去查看` 处理待办。

**关键按钮**：4 张快捷卡片、`查看工资单明细`、待办 `去确认`/`去查看`

> 截图位置：〔占位 - 首页四宫格 + 工资概览 + 待办〕

### 2.2 我的工资单 `/self/payslip`

**页面是什么**：查看本月工资明细，确认无误或提交异议。

**怎么操作**：
1. 顶部 `Select` 下拉切换月份（如 `2026-08`）。
2. 查看三列明细：**应发项**（绿）、**扣款项**（红）、**社保 / 个税**（红）。
3. 核对底部三项汇总：`应发合计` / `扣款合计` / `实发合计`。
4. 无误 → 点 `确认工资单`（按钮变灰显示 `已确认`）。
5. 有问题 → 点 `我有异议` → 在弹窗填写 `异议说明` → 点 `提交异议`。

**关键按钮**：`确认工资单`、`我有异议` → `提交异议`

> 状态标签：黄色 `待确认` → 绿色 `已确认`。

### 2.3 我的假期余额 `/self/leave`

**页面是什么**：查看 4 类假期余额与请假记录，发起请假申请。

**怎么操作**：
1. 查看 4 张余额卡片：`年假`（环形进度，剩余天）、`调休`（环形进度，剩余小时）、`病假`（本年已用）、`事假`（本月已用）。
2. 注意调休卡片：过期前 14 天变红提示「即将过期」。
3. 点 `申请请假` 打开弹窗。
4. 依次填写：`假种`（年假/调休/病假/事假）→ `起止日期`（RangePicker）→ `请假原因` → 病假需点 `点击上传` 上传病历。
5. 点 `提交申请`，提示「请假申请已提交，等待审批」。
6. 下方「最近请假记录」表格查看历史申请状态。

**关键按钮**：`申请请假` → `提交申请`、`点击上传`（病假附件）

> 状态标签：绿色 `已批准`、蓝色 `审批中`、红色 `已驳回`。

### 2.4 我的考勤 `/self/attendance`

**页面是什么**：查看本月考勤统计与异常清单，发起补卡申请。

**怎么操作**：
1. 查看顶部 5 个统计卡片：`应出勤天数` / `实际出勤天数` / `迟到次数` / `缺卡次数` / `旷工天数`。
2. 查看「本月异常清单」表格，含日期、类型、描述、扣款、状态。
3. 有缺卡 → 点 `补卡申请` 打开弹窗。
4. 填写：`补卡日期` → `补卡类型`（上班补卡/下班补卡/全天补卡）→ `补卡原因`。
5. 点 `提交申请`，提示「补卡申请已提交，等待审批」。

**关键按钮**：`补卡申请` → `提交申请`

> 异常类型颜色：迟到（黄）/ 缺卡（橙）/ 旷工（红）。

## 第三部分：HR 管理后台操作

### 3.1 员工档案 `/hr/employees`

**页面是什么**：全集团员工档案管理，支持搜索、筛选、查看详情。

**怎么操作**：
1. 查看顶部 4 张统计卡片：`总人数` / `在职` / `试用期` / `按板块分布`。
2. 在搜索框输入 `搜索姓名 / 工号`，或用 `按部门筛选`、`按板块筛选` 下拉过滤。
3. 点 `重置筛选` 清空所有筛选条件。
4. 表格每行点 `查看详情` 弹窗显示员工完整信息（工号、入职/转正日期、部门、岗位、职级、板块、工作地、状态）。
5. 点 `关闭` 退出详情。

**关键按钮**：`搜索姓名 / 工号`、`按部门筛选`、`按板块筛选`、`重置筛选`、`查看详情`

> 板块标签颜色：康源美宏（橙）/ 福祉教育（蓝）/ 耆祥（绿）/ 集团总部（灰）。

### 3.2 月度核算 `/hr/payroll`

**页面是什么**：DAG 驱动的月度薪酬核算，一键启动全集团核算并查看结果。

**怎么操作**：
1. 查看顶部 4 张 KPI 卡片：`本月应发总额` / `本月实发总额` / `本月扣款总额` / `本月核算人数`。
2. 点右上角大号橙色按钮 `启动月度核算`。
3. 弹窗显示仪表盘进度（0% → 100%），下方文字提示「正在执行核算节点... X%」。
4. 进度到 100% 提示「月度核算完成，所有节点已处理」，点 `完成` 关闭。
5. 查看「核算流程（DAG 节点）」可视化：11 个节点从 `基础工资`→`缺勤扣款`→...→`应发合计`→`社保扣缴`+`个税预扣`→`实发合计`，已完成变绿、进行中转圈、待执行灰显。
6. 下方「月度核算结果」表格按员工列示应发/扣款/实发/状态，底部 `合计` 行汇总。

**关键按钮**：`启动月度核算`、进度弹窗 `完成`

> DAG 节点状态：绿色 `已完成`、橙色 `进行中`、灰色 `待执行`。

### 3.3 异常处理 `/hr/anomalies`

**页面是什么**：处理全集团月度考勤异常，支持撤销扣款与状态流转。

**怎么操作**：
1. 查看顶部 4 张统计卡片：`迟到次数` / `缺卡次数` / `旷工次数` / `待处理数`。
2. 表格中**待处理行**浅橙底高亮，**已处理行**置灰。
3. 每行 3 个操作：
   - `查看` → 弹窗显示异常详情（编号、状态、工号、姓名、类型、日期、描述、扣款金额）。
   - `撤销扣款` → 二次确认「确认撤销此扣款？」→ 确认后扣款归零（扣款已为 0 时按钮禁用）。
   - `标记已处理` → 二次确认「确认标记为已处理？」→ 状态变为 `已处理`（已是已处理时禁用）。
4. 处理完成后行底色变灰。

**关键按钮**：`查看`、`撤销扣款`、`标记已处理`

### 3.4 规则配置 `/hr/rules`

**页面是什么**：管理薪酬、考勤、假期等核算规则，支持版本追溯与风险标记。

**怎么操作**：
1. 查看顶部 3 张统计卡片：`规则总数` / `合规规则数` / `风险规则数`。
2. 点 `新增规则` 打开新增弹窗。
3. 表格每行 2 个操作：
   - `编辑` → 弹窗修改规则名称、模式、描述、风险等级。
   - `历史版本` → 弹窗查看变更记录与回滚。
4. 风险列标签：绿色 `合规` / 黄色 `中风险` / 红色 `高风险`。

**关键按钮**：`新增规则`、`编辑`、`历史版本`

> 高管关注的合规风险明细见第四部分「合规风险」页。

**页面是什么**：集团人资核心指标一屏总览。

**怎么看数据**：

**页面是什么**：三大业务板块横向对比。

**怎么看数据**：

2. 「板块对比雷达图」6 维度对比：员工规模、月度成本、均薪水平、异常率（越高代表异常越少）、人均产能、合规率。
3. 「板块均薪对比」横向柱状图：均薪从低到高排列，右侧标注金额。

**关键指标**：员工数、月度成本、均薪、月度异常数

> 当前数据：美宏 168 人 / 均薪 ¥15,952；福祉 96 人 / 均薪 ¥12,291；耆祥 50 人 / 均薪 ¥8,520。

### 4.3 合规风险 `/dashboard/compliance`

**页面是什么**：规则合规风险监控与法律对照。

**怎么看数据**：
1. 顶部 3 张统计卡片：`合规规则数` / `中风险数` / `高风险数`。
2. 「重点风险」红框卡片：突出显示高风险规则（如 `R-003 法定节假日加班费`），含 `企业现状`（红）/ `法律要求`（绿）/ `差距分析` / `整改建议`（橙）。
3. 「风险规则清单」表格：列出全部规则及建议列。
4. 点击中/高风险行前的展开图标，查看「企业现状 vs 法律要求 vs 整改建议」三栏对照。高风险行红色左边框 + 浅红底重点强调。

**关键指标**：高风险数（当前重点：R-003 法定节假日加班应按 300% 发放，不得以调休替代）

## 第六部分：常见问题 FAQ

**Q1：登录后页面空白或跳回登录页？**
A：未登录或登录态丢失。回到 `/login` 重新选择身份登录；生产环境检查钉钉容器免登是否正常。

**Q2：工资单金额对不上怎么办？**
A：在 `/self/payslip` 点 `我有异议`，详细填写异议说明后提交，HR 会尽快处理并反馈。

**Q3：调休快过期了怎么处理？**
A：在 `/self/leave` 查看「调休余额」卡片（红色提示即将过期），点 `申请请假` 选 `调休` 提交申请，审批通过后使用。

**Q4：月度核算启动后能中断吗？**
A：进度弹窗显示期间可点 `关闭`（未完成时按钮为默认色）。已完成节点不会回滚，建议等进度到 100% 再关闭。

**Q5：HR 误扣了员工考勤款如何补救？**
A：在 `/hr/anomalies` 找到对应异常行，点 `撤销扣款`（二次确认后扣款归零），再视情况 `标记已处理`。

**Q6：高管看不到 HR 管理菜单？**
A：角色权限设计如此。高管仅可见「高管驾驶舱 + 我的首页」；如需 HR 操作能力，联系管理员调整工号权限。

## 附录：键盘快捷键与移动端使用提示

### 快捷键

| 快捷键 | 作用 |
|---|---|
| `Alt + ←` | 浏览器返回上一页 |
| `Ctrl + F5` | 强制刷新页面 |
| `Esc` | 关闭当前弹窗（Modal） |

### 移动端使用提示

- 平台为响应式 H5，手机浏览器直接访问部署 URL 即可。
- 嵌入钉钉时在钉钉内打开应用，自动免登。
- 表格在窄屏会横向滚动，左右滑动查看完整列。
- 卡片栅格在移动端自动堆叠为单列。
- 弹窗（Modal）在移动端全屏展示，顶部有 `×` 关闭按钮。
- 建议竖屏使用员工自助功能，横屏查看驾驶舱图表更清晰。
