# 康源集团智能考勤与薪酬自动化平台 设计规格

> change-id: design-intelligent-hr-payroll-platform
> 范围：康源集团（福祉教育、上海博曜、康源美宏、书院街代缴）全体员工的考勤采集、薪酬核算、社保公积金、个税、工龄、绩效、补贴全流程自动化

---

## 一、Why（为什么要做）

康源集团人资员工与机构行政每月初被淹没在大量机械、低水平、繁琐的考勤核对与工资计算工作中。经对桌面《7月教育工资》《6月教育工资》两个文件夹的全部资料表格、钉钉打卡原始记录、社保公积金缴费明细、住房公积金汇缴核定单、钉钉通用审批PDF 等一手资料的详细分析，发现当前考勤与工资核算处于**半手工Excel操作+多源数据人工搬运+跨主体人工对账**状态，存在严重的效率瓶颈、错误风险与人力浪费。

核心痛点：每月耗费人资/行政大量工时在数据收集、表格填写、公式计算、跨表核对上；规则散落在多份Excel和口头约定中，标准不统一；任何一处手工录入失误都会导致工资错误；入职/离职/调动等异动需人工判断计薪规则；社保基数、公积金基数、个税累计预扣均依赖人工查表计算。集团需要一套**完全贴合当下运作实情、能替代全部人工核算与复核工作、实现自动出考勤出工资、准确无误有理有据**的智能化平台，彻底将人资从低等低效工作中解放出来。

---

## 二、What Changes（要做什么）

构建「康源智能考勤与薪酬自动化平台」，将当前手工Excel驱动的月度考勤-工资核算全流程升级为**数据自动采集→规则自动引擎→工资自动生成→异常自动预警→人资只做最终确认**的全自动闭环。

- 新建统一主数据中台：员工档案、岗位薪级、社保公积金基数、工龄、银行账户等基础数据集中管理，告别散落Excel
- 新建考勤自动采集引擎：直连钉钉考勤打卡数据，自动生成月度考勤汇总，自动识别加班/调休/迟到/缺勤
- 新建薪酬计算规则引擎：内置全部工资公式、社保比例、公积金比例、个税累计预扣算法、工龄工资规则、绩效应用规则
- 新建异动自动处理模块：入职/离职/调动自动按规则切分计薪天数、工龄归属、社保转移
- 新建多主体对账模块：福祉教育、上海博曜、康源美宏、书院街代缴 自动分主体核算与汇总
- 新建审批集成模块：钉钉通用审批（课时费、补贴等）自动抓取并入工资
- 新建AI异常检测Agent：自动识别考勤异常、数据矛盾、计算偏差，生成异常清单
- 新建自动归档与审计模块：每月考勤、工资全量留痕，有理有据可追溯
- **BREAKING**：取消手工Excel工资表/考勤汇总表的编写流程，改为系统自动生成+人资确认

## 三、Impact（影响范围）

- 影响业务流程：考勤管理、工资核算、社保公积金申报、个税申报、工龄管理、绩效应用、各类补贴核算、入离职调动计薪
- 影响组织主体：陕西康源福祉教育科技、上海康源博曜科技、康源美宏（养老）、书院街代缴（袁梅）
- 影响角色：集团人资、机构行政、财务、各主体负责人、全体员工（自助查询）
- 影响数据源：钉钉考勤打卡、钉钉审批、钉钉花名册、社保公积金基数表、住房公积金汇缴核定单、工龄台账、绩效台账
- 影响输出：月度考勤汇总表、月度工资表、社保公积金缴费明细、个税明细、银行代发文件、住房公积金汇缴清册

### 4.4 钉钉打卡原始记录分析

《美宏福祉7月份.xlsx》「美宏钉钉打卡记录」Sheet 是钉钉考勤月度汇总导出，结构为：

- 每个员工一行，列从「出勤天数」「休息天数」「工作时长」「迟到次数」一直延伸到第31天（每日一列）
- 每日打卡状态格式：`机构行政班次:正常\n(08:20,18:24)`、`休息\n(-)`、`机构行政班次:上班外勤,机构行政班次:上班迟到1分钟\n(08:31,18:14)`、`机构行政班次:正常,补卡申请07-31 08:30到07-31 08:30\n(08:30,18:14)`
- 大量员工标注「未加入考勤组」「离职」状态

**关键发现**：钉钉已具备完整打卡数据，但当前流程是人工导出后手动填入考勤汇总表，存在大量重复劳动与转抄错误风险。

1. 社保费：每月10号前完成钉钉付款审批，确保金额与社保缴费客户端一致

## 五、考勤与工资核算的全部公式与底层逻辑

### 5.1 考勤计算公式

```
月应计薪天数 = 当月应工作天数 + 法定节假日天数
实际计薪天数 = 月应计薪天数 - 病假天数 - 事假天数 - 异动缺勤 - 旷工天数 + 入职调整
  其中入职调整：
    - 入职日期在1-15日（含）：当月全额计薪
    - 入职日期在16日（含）后：当月按实际出勤计薪
    - 离职：按离职日前实际出勤计薪

全勤奖判定 = (迟到早退次数≤允许次数) AND (无病假) AND (无事假) AND (无旷工) AND (无异动缺勤)
迟到早退补卡超限次数 = MAX(0, 迟到早退补卡总次数 - 3)
累计剩余存休 = 上月结转 + 本月公休日加班 + 本月节假日加班 - 本月已调休
```

### 5.2 工资计算公式

```
日工资 = 基本工资标准 ÷ 月应计薪天数
出勤工资 = 基本工资标准 × (实际计薪天数 ÷ 月应计薪天数)
加班费 = 公休日加班天数 × 日工资 × 200% + 节假日加班天数 × 日工资 × 300%
工龄工资 = 司龄（年）× 100元/年
绩效工资 = 绩效工资标准 × (季度绩效分数 ÷ 100) × 绩效应用比例
交通补贴 = 双人服务人次 × 5 + 单人服务人次 × 10
课时费 = 课时数 × 100 + 交通次数 × 100  （来自审批）

应发工资 = 出勤工资 + 当月绩效工资 + 工龄工资 + 加班费 + 交通补贴 + 课时费 + 其他补贴
```

### 5.3 社保公积金公式

```
养老（单位）= 养老基数 × 16%
养老（个人）= 养老基数 × 8%
医疗+生育（单位）= 医疗基数 × 单位比例
医疗（个人）= 医疗基数 × 个人比例
失业+工伤（单位）= 失业基数 × 单位比例
失业（个人）= 失业基数 × 个人比例
住房公积金（单位）= 公积金基数 × 5%
住房公积金（个人）= 公积金基数 × 5%

五险合计（个人）= 养老个人 + 医疗个人 + 失业个人
公积金合计（个人）= 住房公积金个人
五险一金合计 = 五险合计 + 公积金合计
```

### 5.4 个税公式（累计预扣法）

```
累计预扣预缴应纳税所得额 = 累计收入 - 累计免税收入 - 累计减除费用(5000×月数) - 累计专项扣除(五险) - 累计专项附加扣除
本期应预扣预缴税额 = (累计预扣预缴应纳税所得额 × 预扣率 - 速算扣除数) - 累计已预扣预缴税额
  预扣率表（累计）：
    ≤36000：3%，速算0
    ≤144000：10%，速算2520
    ≤300000：20%，速算16920
    ≤420000：25%，速算31920
    ≤660000：30%，速算52920
    ≤960000：35%，速算85920
    >960000：45%，速算181920

实发工资 = 应发工资 - 五险一金（个人部分） - 个税
```

### 5.5 工龄归属判定逻辑（跨主体调动）

```
IF 调动日期在1-15日（含）:
    工龄工资归属 = 新公司（当月生效）
IF 调动日期在16日（含）后:
    工龄工资归属 = 原公司（次月才在新公司生效）

IF 入职日期在1-15日（含）:
    工龄工资生效月 = 入职当月
IF 入职日期在16日（含）后:
    工龄工资生效月 = 入职次月
```

### 5.6 假期类工资计算公式（来自考勤管理制度）

```
日薪 = 基本工资标准 ÷ 月应计薪天数

=== 病假工资（梯度计算） ===
IF 当月病假累计 ≤ 7日:
    病假期日工资 = 日薪 × 80%
IF 当月病假 7日 < 累计 ≤ 15日:
    病假期日工资 = 日薪 × 50%
IF 当月病假累计 > 15日:
    病假期日工资 = 当地最低工资标准 × 80% ÷ 21.75

=== 事假工资 ===
事假期日工资 = 0（不计发工资）
注意：若当月工资不足以缴纳社保个人部分，员工需将差额缴至公司

=== 年休假工资 ===
年休假期间日工资 = 日薪 × 100%（全额支付）
年休假可抵扣病假/事假（优先使用年假抵扣）

=== 调休假工资 ===
调休期间视为对应出勤（正常计薪）
调休可冲抵病假/事假，不可冲抵迟到/早退/旷工

=== 婚假/产假/陪产假/丧假/工伤假工资 ===
假期期间日工资 = 日薪 × 100%（全额支付）

=== 产检假 ===
视为正常出勤（全额计薪），每月1天
```

### 5.7 考勤奖惩计算公式

```
=== 全勤奖 ===
IF (出勤整月) AND (补卡次数 ≤ 3) AND (无病假) AND (无事假) AND (无迟到早退) AND (无旷工)
    AND (非新入职当月) AND (非离职当月):
    全勤奖 = 100元
ELSE IF (新入职当月达到实际月应出勤天数):
    全勤奖 = 100元
ELSE:
    全勤奖 = 0元

=== 迟到/早退扣款 ===
迟到早退扣款 = 迟到早退次数 × 10元
（注：迟到/早退超30分钟→按事假半天处理；超60分钟→按旷工1天处理）

=== 补卡超限扣款 ===
补卡超限扣款 = MAX(0, 补卡次数 - 3) × 10元

=== 旷工扣款 ===
旷工扣款 = 旷工天数 × 日薪（旷工期间不计发工资）
IF 旷工天数 ≥ 2 或 累计旷工次数 ≥ 2:
    触发"严重违反规章制度"预警 → 可解除劳动合同
IF 旷工天数 = 1:
    扣发当月全部绩效工资 + 通报批评

=== 迟到早退累计处罚 ===
IF 月度迟到早退累计 ≥ 3次:
    扣发当月全部绩效工资 + 书面警告 + 不得参加月度奖金及评优
IF 月度迟到早退累计 ≥ 5次:
    触发"降职/降级/降薪或解除劳动合同"预警
```

### 5.8 试用期与调动计薪公式

```
=== 试用期工资 ===
试用期月工资 = 岗位等级薪资标准 × 80%
转正后月工资 = 岗位等级薪资标准 × 100%

=== 试用期请假影响 ===
IF 试用期请假累计 ≤ 3天:
    转正日期顺延（请假天数）
IF 试用期请假累计 > 3天:
    终止试用 → 按离职流程结算

=== 未满5天自动离职 ===
IF 入职后工作未满5天（含5天）自动离职:
    不予结算薪资

=== 调动调休假折算 ===
IF 调动至新公司:
    剩余调休假 → 在原公司调休或折算薪资（不延续至新公司）
    剩余年假 → 顺延至新公司
```

### 5.9 橄榄枝协议留用奖励与福利计算公式（全新规则）

```
=== 橄榄枝留用奖励 ===
IF 橄榄枝协议期限 = 1年:
    合同签订次月工资 → 橄榄枝奖励 = 1500元（一次性）
IF 橄榄枝协议期限 = 3年:
    合同签订次月工资 → 橄榄枝奖励 = 6000 × 40% = 2400元（第1期）
    合同签订后满1整年月工资 → 橄榄枝奖励 = 6000 × 30% = 1800元（第2期）
    合同签订后满2整年月工资 → 橄榄枝奖励 = 6000 × 30% = 1800元（第3期）
IF 橄榄枝协议期限 = 5年:
    合同签订次月工资 → 橄榄枝奖励 = 12000 × 40% = 4800元（第1期）
    合同签订后满1整年月工资 → 橄榄枝奖励 = 12000 × 15% = 1800元（第2期）
    合同签订后满2整年月工资 → 橄榄枝奖励 = 12000 × 15% = 1800元（第3期）
    合同签订后满3整年月工资 → 橄榄枝奖励 = 12000 × 15% = 1800元（第4期）
    合同签订后满4整年月工资 → 橄榄枝奖励 = 12000 × 15% = 1800元（第5期）

=== 七天带薪休假（橄榄枝福利） ===
IF 签订正式劳动合同后:
    自动赋予 七天带薪休假余额 = 7天
    有效期 = 合同签订日期 + 1年（自动到期清零）
    约束: 休假申请时自动校验，不允许与年假/福利假连休（若检测到连续休假申请包含年假则拦截）

=== 明星员工月度奖励 ===
IF 员工当月被评为明星员工:
    明星员工奖励 = 奖励标准（具体金额按集团月度方案配置）→ 计入当月工资

=== 介护等级评定关联薪资 ===
IF 护理一线岗介护等级评定结果变更（见习介护师→介护师→护理主管等）:
    自动更新岗位薪级主数据 → 下月按新等级标准计薪
    （等级标准: 见习介护师<介护师<护理主管<护理部长<副院长<院长，每级对应不同薪级区间）

=== 年度奖励 ===
年度奖励 = 按项目盈利情况 × 方案分配系数 × 员工绩效系数
（方案每年配置后自动计算，年底一次性或分季度发放）

=== 橄榄枝违约追回 ===
IF 员工在橄榄枝协议期内提前离职（未完成合同期限）OR 被认定为不能胜任岗位:
    应追回留用奖励金额 = 本协议累计已发放奖励总额
    → 自动生成追回预警，通知人资
    → 可在离职工资结算时一次性扣除（如工资不足则生成应收台账）

=== 调动橄榄枝协议继承 ===
IF 员工因工作原因跨公司调动:
    橄榄枝协议剩余条款自动继承至新岗位
    未发放的后续期奖励按新公司发放节奏继续
```

### 5.10 星青年储备人才培养跟踪公式

```
=== 培养周期自动提醒 ===
培养周期里程碑提醒时间点:
  - 周期3-6个月: 开始后每1.5个月提醒
  - 周期6-12个月: 开始后每3个月提醒
  - 周期1-2年: 开始后每6个月提醒

IF 培养周期到期:

IF 评估通过达到晋升标准:
    自动触发晋升审批流程（调岗/调薪联动）
```

### 6.2 根本性问题

1. **数据孤岛**：钉钉考勤、钉钉审批、社保基数表、公积金核定单、工龄台账、绩效台账各自独立，无统一主数据
2. **手工搬运链**：数据从源头到最终工资表平均经手4-5次人工转抄，每次转抄都是错误注入点
3. **规则不可执行**：规则以文字和口头形式存在，未固化为可执行算法，依赖人工判断
4. **无异常检测**：任何错误只能在最终人工复核时发现，无自动校验机制
5. **多主体割裂**：福祉、博曜、美宏、书院街各自为政，无统一核算视图
6. **无自助透明**：员工无法自助查询考勤与工资明细，全部依赖人资解答

### 7.2 核心模块设计

#### 模块1：主数据中心
- 员工主数据：姓名、身份证、手机号、入职日期、调动记录、离职日期、所属主体、岗位、薪级
- 薪级主数据：岗位→基本工资标准、绩效工资标准
- 社保公积金主数据：员工→各主体社保基数、公积金基数、缴存比例
- 工龄台账：起算时间、截止时间、司龄、工龄工资、调动归属规则
- 绩效台账：季度绩效分数、应用比例、应用月份
- 银行账户主数据：工资卡、开户行

#### 模块2：考勤自动采集引擎
- 直连钉钉考勤API，按月自动拉取全员打卡原始记录
- 自动解析每日打卡状态（正常/迟到/早退/外勤/补卡/缺卡/休息）
- 自动统计：出勤天数、迟到早退次数、补卡次数、加班天数（公休日/节假日）

## 八、ADDED Requirements（新增需求）

### Requirement: 考勤自动采集与汇总
系统 SHALL 直连钉钉考勤API，每月自动拉取全员打卡原始记录，自动解析每日打卡状态，自动统计出勤/迟到/早退/加班/调休/缺勤，自动生成月度考勤汇总表，无需人工导出Excel或手工填写。

#### Scenario: 月初自动生成考勤
- **WHEN** 每月1日系统定时任务触发
- **THEN** 自动拉取上月钉钉全员工打卡记录
- **AND** 自动关联上月所有考勤类审批（病假/事假/调休/加班/补卡）
- **AND** 自动生成与当前考勤汇总表格式一致的汇总数据
- **AND** 自动标注异常项（未打卡/审批缺失）供人资确认

### Requirement: 异动自动计薪
系统 SHALL 根据员工入职/离职/调动记录，自动按规则计算当月计薪天数、工龄归属主体、社保缴纳主体，无需人工判断。

#### Scenario: 月中入职
- **WHEN** 员工入职日期为当月15日（含）前
- **THEN** 当月按全额计薪
- **WHEN** 员工入职日期为当月16日（含）后
- **THEN** 当月按实际出勤天数计薪

#### Scenario: 跨主体调动工龄归属
- **WHEN** 调动日期为1-15日（含）
- **THEN** 工龄工资在当月归属新公司
- **WHEN** 调动日期为16日（含）后
- **THEN** 工龄工资当月归属原公司，次月才在新公司生效

### Requirement: 薪酬全自动计算
系统 SHALL 内置全部工资、社保、公积金、个税公式为可执行算法，输入考勤结果与主数据后自动生成完整工资表，包含应发、五险一金、个税、实发，无需人工套用Excel公式。

#### Scenario: 一键生成月度工资
- **WHEN** 考勤汇总确认完成
- **THEN** 自动按主体（福祉/博曜/美宏/书院街）生成工资表
- **AND** 自动计算每位员工应发工资、五险一金、个税、实发工资
- **AND** 自动生成合计行并校验平衡

### Requirement: 社保公积金自动核算
系统 SHALL 按主体自动匹配社保公积金缴费基数与比例，自动计算单位与个人缴费，自动生成社保缴费明细表与住房公积金汇缴清册。

#### Scenario: 多主体社保分账
- **WHEN** 员工社保由不同主体代缴（如书院街代缴袁梅）
- **THEN** 自动按代缴主体分别计算
- **AND** 自动生成各主体社保缴费明细

### Requirement: 审批自动集成
系统 SHALL 自动抓取钉钉通用审批中涉及薪酬的审批（课时费、交通补贴、其他补贴），审批通过后自动并入当月工资，无需人工读取PDF。

#### Scenario: 课时费审批并入工资
- **WHEN** 钉钉通用审批「课时费申请」通过
- **THEN** 自动提取课时数、金额、涉及人员
- **AND** 自动并入对应员工当月工资

### Requirement: AI异常检测与预警
系统 SHALL 配备AI Agent自动检测考勤与工资数据异常，生成异常清单推送人资确认，替代人工逐行核对。

#### Scenario: 考勤与工资不一致预警
- **WHEN** 某员工考勤出勤天数与工资计薪天数不一致
- **THEN** 自动标记异常并推送人资
- **AND** 提供异常原因推测

### Requirement: 多主体对账与汇总
系统 SHALL 自动按福祉、博曜、美宏、书院街分主体核算，并生成集团合并视图，自动核对跨主体调动员工不重复不遗漏。

### Requirement: 自助查询与在线确认
系统 SHALL 提供员工自助查询考勤与工资明细，提供人资一键确认/退回，提供负责人在线签字确认，替代线下签字照片流程。

### Requirement: 审计留痕与可追溯
系统 SHALL 对每月考勤、工资全量留痕，保留规则版本、计算过程、确认记录，支持任意月份回溯审计，实现有理有据。

### Requirement: 社保公积金平台操作自动化
系统 SHALL 对接养老、工伤失业、医保、公积金4个平台，自动跟踪各险种增减员时间节点（养老28日前/6号前、工伤失业1日至月末、医保次月生效、公积金当月生效），自动生成增减员待办清单，自动发起钉钉付款审批，替代人工登录4个平台逐一操作。

#### Scenario: 入离职触发社保增减员
- **WHEN** 员工入职或离职
- **THEN** 自动生成各险种增减员待办（含时间节点提醒）
- **AND** 自动识别各险种生效时间差异（养老当月/医保次月/公积金当月）

#### Scenario: 超龄工伤到期提醒
- **WHEN** 超龄工伤即将到期（如田冬梅2027/3/3、李文青2027/5/7）
- **THEN** 提前30天自动提醒人资处理续保或停保

### Requirement: 跨主体资金转账自动化
系统 SHALL 自动识别跨主体社保代缴关系（上海→福祉、福祉→书院街），自动生成转账付款审批，定期发送，替代人工发起。

### Requirement: 月度SLA时间节点管理
系统 SHALL 内置月度工作流程时间节点（月底更新花名册→3号考勤绩效→9号个税核定签批→10号发放），自动按时间节点推进各环节并预警延迟，替代人工记忆与赶工。

#### Scenario: 时间节点自动推进
- **WHEN** 每月3号17:00前
- **THEN** 自动完成考勤汇总、绩效应用、课时费、补贴、工龄工资计算
- **AND** 如未完成自动预警人资

### Requirement: 课时费分级自动计算
系统 SHALL 内置课时费分级标准（整期600/按课时720/照护师720/护理员240/单次180），根据培训类别自动匹配费率并按教师拆分到个人，替代人工查表。

### Requirement: 转正与协议到期自动跟进
系统 SHALL 自动跟踪员工转正日期（如王海涛6/1、杨发强7/1）和协议到期日（如栗恒华6/31），提前提醒人资处理。

### Requirement: 假期管理与假期余额自动化
系统 SHALL 内置全部假期类型规则（事假/病假/年休假/婚假/产假/陪产假/丧假/调休假/工伤假/产检假），自动管理假期余额、有效期、抵扣优先级，自动计算各类假期的工资发放比例，替代人工查表与分段计算。

#### Scenario: 病假工资梯度自动计算
- **WHEN** 员工当月病假累计≤7日
- **THEN** 病假期工资按日薪×80%自动计算
- **WHEN** 员工当月病假7日<累计≤15日
- **THEN** 病假期工资按日薪×50%自动计算
- **WHEN** 员工当月病假累计>15日
- **THEN** 病假期工资按当地最低工资标准×80%自动计算

#### Scenario: 年假余额与有效期自动管理
- **WHEN** 员工累计工作满1年
- **THEN** 自动赋予年假余额（1-10年=5天/10-20年=10天/20年+=15天）
- **AND** 自动判定有效期（上半年入职→当年年底；下半年入职→次年6月底）
- **AND** 年假可自动抵扣病假/事假（优先使用年假抵扣）

#### Scenario: 调休冲抵规则自动执行
- **WHEN** 员工有调休余额且有病假/事假
- **THEN** 调休自动冲抵病假/事假（视为对应出勤）
- **AND** 调休不可冲抵迟到/早退/旷工（系统自动拦截）

#### Scenario: 不享受年假情形自动判定
- **WHEN** 员工年度事假累计>30天 或 病假累计超限（1-10年>2月/10-20年>3月）
- **THEN** 自动标记不享受当年年假
- **AND** 已休年假按事假从工资中补扣

### Requirement: 考勤奖惩自动判定与扣款
系统 SHALL 根据考勤管理制度自动判定全勤奖、迟到/早退扣款、补卡超限扣款、旷工扣款，自动执行迟到超时限等级转换（30分钟→事假半天/60分钟→旷工1天），自动跟踪累计处罚阈值（3次扣绩效/5次可解除合同/旷工2天可解除合同），替代人工统计与计算。

#### Scenario: 全勤奖自动判定
- **WHEN** 月度考勤汇总完成
- **THEN** 自动判定全勤奖（出勤整月+补卡≤3次+无请假+无迟到早退+无旷工+非新入职/离职当月）
- **AND** 新入职当月若达到实际月应出勤天数也判定全勤
- **AND** 全勤奖100元自动计入工资

#### Scenario: 迟到超时限等级自动转换
- **WHEN** 员工迟到/早退超过30分钟
- **THEN** 自动转为事假半天处理（不再按迟到扣款）
- **WHEN** 员工迟到/早退超过60分钟
- **THEN** 自动转为旷工1天处理

#### Scenario: 累计处罚阈值自动预警
- **WHEN** 月度迟到早退累计≥3次
- **THEN** 自动扣发当月绩效工资 + 生成书面警告 + 标记不得参加月度评优
- **WHEN** 月度迟到早退累计≥5次
- **THEN** 触发"降职/降级/降薪或解除劳动合同"预警推送人资
- **WHEN** 旷工≥2天或累计旷工≥2次
- **THEN** 触发"严重违反规章制度可解除合同"预警推送人资

#### Scenario: 月底未完成审批自动转旷工
- **WHEN** 月底仍有未完成审批的请假/出差/补卡
- **THEN** 自动按旷工处理并计入考勤

### Requirement: 试用期全流程自动化
系统 SHALL 自动管理试用期薪资（80%标准）、试用期请假影响（3天内延长转正/超3天终止）、试用期考核节点（入职1周签目标书→月度评估→期满前2周综合评估→述职）、未满5天离职不予结算薪资等规则。

#### Scenario: 试用期请假影响转正
- **WHEN** 试用期员工请假累计≤3天
- **THEN** 自动延长转正日期（延长天数=请假天数）
- **WHEN** 试用期员工请假累计>3天
- **THEN** 自动触发终止试用流程预警

#### Scenario: 未满5天离职不予结算
- **WHEN** 员工入职后工作未满5天（含5天）自动离职
- **THEN** 自动标记不予结算薪资

### Requirement: 调动调休年假自动处理
系统 SHALL 在跨主体调动时自动处理调休假（原公司调休或折算薪资，不延续）和年假（顺延至新公司），自动设置3个月观察期，自动更新考勤系统设置。

### Requirement: 离职流程自动化
系统 SHALL 自动校验辞职提前期（试用期3日/转正后30日），自动跟踪离职交接完成状态，自动在交接完成后于发薪日统一结算离职工资，自动识别服务期违约金和竞业限制义务。

#### Scenario: 辞职提前期校验
- **WHEN** 试用期员工提交辞职申请
- **THEN** 自动校验是否提前≥3日
- **WHEN** 转正后员工提交辞职申请
- **THEN** 自动校验是否提前≥30日

### Requirement: 橄榄枝协议留用奖励自动化
系统 SHALL 内置橄榄枝协议全周期管理能力，自动跟踪合同期限（1/3/5年）对应的留用奖励分期发放节点和金额（1500/6000/12000元及比例40%/30%/30%或40%/15%×4），自动在发放节点当月计入工资，自动管理七天带薪休假（签约后赋予7天，有效期1年，禁止与年假连休），自动在服务期内离职时核算应追回的已发放留用奖励总额，跨公司调动时自动继承协议条款。

#### Scenario: 3年期橄榄枝奖励分批发放
- **WHEN** 员工签订3年期橄榄枝协议
- **THEN** 合同签订次月工资自动计入2400元（6000×40%）
- **AND** 签订后满1整年月工资自动计入1800元（6000×30%）
- **AND** 签订后满2整年月工资自动计入1800元（6000×30%）

#### Scenario: 七天带薪休假有效期与连休拦截
- **WHEN** 员工签订正式劳动合同
- **THEN** 自动赋予七天带薪休假余额7天，有效期1年
- **AND** 休假申请若与年假/福利假连续则自动拦截并提示

#### Scenario: 服务期内离职留用奖励追回
- **WHEN** 橄榄枝协议期内员工提前离职或被认定不能胜任
- **THEN** 自动计算应追回金额=本协议累计已发放奖励总额
- **AND** 离职工资结算时自动扣除（工资不足则生成应收台账并预警）

#### Scenario: 跨公司调动协议继承
- **WHEN** 员工跨主体调动且仍在橄榄枝协议期内
- **THEN** 协议剩余条款自动继承至新岗位
- **AND** 未发放的后续期奖励按新公司发放节奏继续

### Requirement: 明星员工/介护等级/年度奖励自动化
系统 SHALL 将明星员工月度评选结果自动关联当月工资补贴，介护等级评定（护理一线岗）结果自动触发岗位薪级更新，年度奖励根据配置的盈利系数、分配系数、绩效系数自动计算，无需手工录入与计算。

#### Scenario: 明星员工奖励自动入账
- **WHEN** 当月明星员工评选结果录入（使用明星员工评选推荐表模板）
- **THEN** 明星员工奖励自动计入当月工资补贴项

#### Scenario: 介护等级评定自动调薪
- **WHEN** 护理岗员工介护等级评定结果变更（如：介护师→护理主管）
- **THEN** 自动更新该员工岗位薪级主数据
- **AND** 下月起按新等级薪级计薪

### Requirement: 深造考证档案与培训津贴管理
系统 SHALL 自动记录员工证书档案（失智照护/老年照护/日语等级/营养配餐/心理咨询/健康管理师/老人能力评估师等），关联学历提升、赴日学习等培训记录，按配置规则自动触发培训津贴或薪资等级关联。

### Requirement: 星青年储备人才培养自动化跟踪
系统 SHALL 维护星青年储备人才库，分层管理储备院长/副院长/介护主管，自动跟踪培养周期里程碑并按周期（3-6月/6-12月/1-2年/可随时）推送提醒，培养周期到期自动触发评估流程，评估通过自动推荐晋升，储备人员离职自动标记失效，调动/晋升时自动匹配异地意愿。

#### Scenario: 培养周期到期自动评估与晋升推荐
- **WHEN** 储备人才培养周期到期（如6-12个月到期）
- **THEN** 储备状态自动切换为"待评估"并推送人资/主管
- **AND** 评估结果为"通过并达到晋升标准"时自动触发晋升审批流程

#### Scenario: 储备人才离职自动失效
- **WHEN** 储备人员发生离职异动
- **THEN** 星青年储备状态自动标记为"已失效（离职）"
