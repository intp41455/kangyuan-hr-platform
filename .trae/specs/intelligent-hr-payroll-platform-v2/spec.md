# 智慧化人资考勤薪酬一体化自动化平台 · V2.0 - 产品需求文档 (PRD)

## Overview
- **Summary**: 基于钉钉开放平台（通讯录/考勤/审批/文档）+ 自研规则引擎 + AI智能代理（Agent）构建的端到端无人值守人资运营平台。覆盖员工主数据中心 → 月度考勤自动采集与异常处理 → 薪酬核算（基本工资/绩效/工龄/加班/假期/社保/个税） → 审批流自动发起与闭环 → 自助确认与申诉 → 工资条生成与推送 → 数据归档与合规审计的全链路。目标：每月核算周期（D-3→D日）人工干预量从当前80人时降低至≤2人时，准确率≥99.9%。
- **Purpose**: 彻底解决当前集团人资专员与机构行政在月初被考勤核对、资料搜集、工资计算、表格汇总等大量机械性重复工作淹没的问题，通过标准化、规则化、智能化、AI驱动的方式，实现集团人资运营从"人算"到"系统算"的根本性变革，释放HR团队从事务性工作转向战略性人力资源管理。
- **Target Users**: 集团HR团队（专员/主管/经理）、各子机构行政岗、财务部门、各层级审批人、全体员工（自助查询/确认）、分管HR与财务的高管层。

---

## Goals
1. **数据零录入**：员工主数据、考勤打卡、假期申请、加班申请、异动审批全部通过钉钉API自动采集，无需任何Excel导入。
2. **规则零歧义**：403+条人资业务规则（假期/考勤/奖惩/薪酬/社保）在规则引擎中可配置、可追踪、可审计，每条规则有唯一R编号、计算公式、生效时间、制度来源。
3. **考勤全自动**：每月最后一日（D-3）自动采集考勤打卡数据 → 自动按部门核算异常（迟到/早退/缺卡/旷工/加班/调休/假期抵扣） → 钉钉机器人自动推送异常待确认单 → 审批流自动生成 → 异常闭环率≥98%在D-2 12:00前。
4. **薪酬全自动**：D-2 14:00自动触发核算引擎 → 基础薪酬+绩效薪酬+工龄工资+加班工资+缺勤扣款+社保公积金+个税专项扣除 + 30项津贴补贴 → 生成工资明细 → 异常检测引擎自动审计 → D-2 18:00前完成100%初算。
5. **审批自动化**：薪酬核算结果超过阈值（±20%环比波动/个税异常/社保基数异常）自动生成OA审批单按审批矩阵流转；异常考勤自动发起"补卡/缺卡说明/加班确认"审批。
6. **员工自助化**：D-1自动推送工资条至员工钉钉工作台，支持在线确认、一键申诉、历史查询、PDF导出。
7. **审计可追溯**：所有核算过程、规则版本、审批记录、人工干预操作自动留痕，生成合规审计报告可下载。
8. **AI决策辅助**：人资专项Agent自动回答制度问题、预测人工成本、预警异常波动、推荐优化措施。

---

## Non-Goals (Out of Scope)
1. **不负责人才招聘/面试流程管理**（ATS系统另议）。
2. **不负责绩效评价的主观打分环节**（只负责分数采集与薪酬映射）。
3. **不做财务总账/会计凭证生成**（只输出标准薪酬数据给财务系统对接）。
4. **不替代钉钉基础打卡功能**（深度集成而非替换）。
5. **不做集团股权/期权/中长期激励管理**（另行建设）。
6. **不做培训与人才发展模块**（LMS系统另议）。
7. **不负责多币种/跨国薪资**（仅覆盖中国大陆社保个税标准）。

## Background & Context

### 现状诊断（5大类22项关键问题，已脱敏）
| 类别 | 问题描述 | 影响量化（估算月度损失） |
|---|---|---|
| ①制度双轨制 | 同一事项存在"制度文件版本"与"微信群口头约定"双轨并行，3项假期清零规则存在冲突 | 每年特殊豁免≥3人次，合规风险等级：高 |
| ②数据孤岛 | 打卡数据/审批数据/员工档案/社保基数分属4个系统，人工手动拼接≥8个Excel表 | 月度数据搬运人时≥56小时，差错率≥12% |
| ③审批不一致 | 费用/薪酬审批阈值同时存在1000元与2000元两版本，审批流缺节点导致延误≥5次/月 | 每月平均延误2个工作日 |
| ④核算复杂度 | 教育板块与非教育板块适用两套完全不同的加班规则（教育岗平日加班按规定规则豁免与常规岗位区分） | 月度加班核算人时≥28小时 |
| ⑤人工依赖 | 月初3天（D-3→D日）80%以上人资/行政人力全部投入核算，任何人员请假或离职即造成流程中断 | 关键岗位单点故障率≥60% |

### 技术栈与集成约束
- **钉钉开放平台深度集成**：通讯录API、考勤API（考勤组规则/打卡详情/班次/统计摘要）、OA审批API（待处理/详情/同意/拒绝/记录/已发起）、群聊机器人、在线表格/文档、钉盘、AI听记、知识库、AI搜问。
- **GitHub代码托管与CI/CD**：所有规则引擎、核算模块、Agent代码通过github托管，每一次规则变更走PR审核、自动测试、灰度发布。
- **本地化运行**：优先企业私有部署，保证员工敏感数据不出企业内网。
- **前端可选**：钉钉小程序/微应用 + Web后台管理端（Vue3 + Element Plus）。
- **后端技术栈**：Node.js 20 LTS（当前已实现Task1主数据中心模型在此基础上扩展）。
- **AI能力**：企业级LLM + RAG检索人资制度知识库 + 推理式规则引擎。

### 数据基线（来自制度文件+6/7月实际薪酬表分析）
- 员工规模：≥4个薪级（专家级/副总级/实习生级/社保代缴级）
- 薪酬结构：9:1（固定90% + 绩效10%）为主力；8:2（部分高管/业务岗）
- 月度考勤项：≥16类（正常/迟到≥3次扣20/早退/外勤/出差/缺卡/请假8类/旷工/加班平日1.5倍周末2倍节假日3倍/调休/年假未休清零）
- 社保公积金核算：≥5个参保地（西安/天水/白银/平凉/兰州），8月起西安医保基数由4990调整至5132

## Functional Requirements

### FR-1：员工主数据中心 (Master Data Hub)
- FR-1.1 员工全生命周期档案管理：入职/转正/调动/晋升/降职/离职8种状态流转，每次异动自动触发历史记录
- FR-1.2 岗位薪级标准库：≥4薪级基础模型，支持基础/绩效/岗位/津贴4维度配置，9:1与8:2比例动态切换
- FR-1.3 多参保地社保基数库：5个地区独立配置，支持年度基数调整、公积金比例（8%/10%/12%）差异化
- FR-1.4 统一编码标准：员工ID/部门ID/岗位ID三级编码，与钉钉通讯录userId/deptId双向映射
- FR-1.5 员工画像字段扩展：自动计算工龄工资（100元/年）、试用期工资标准（转正工资×80%）、首工作日/入职日期双记录

### FR-2：考勤自动化采集与异常处理引擎
- FR-2.1 钉钉考勤组配置读取：自动识别不同考勤组（总部/教育/外地办事处）的打卡时间、弹性规则、免打卡人员
- FR-2.2 月度打卡原始数据自动全量采集：考勤月度内每一天的上下班打卡时间、地点、设备、外勤标记、补卡记录
- FR-2.3 16类考勤异常自动识别：迟到(≥10/≥30min分档)/早退/缺卡(≤2次补免)/旷工/加班时长/请假时长8类/调休抵扣/外勤未审批/出差未审批
- FR-2.4 异常自动派单与催办：识别异常T+1小时内通过钉钉机器人推送至员工+直属上级，每日18:00二次催办
- FR-2.5 教育板块特殊规则引擎：教育岗平日加班按制度区分豁免/非豁免，自动识别岗位标签并切换核算口径
- FR-2.6 补卡审批自动生成：缺卡次数×金额（50元/次，当月≥3次起扣）→ 自动发起"缺卡说明"审批，闭环后自动回写

### FR-3：假期管理与清零规则引擎
- FR-3.1 8类假期统一管理：年假/病假(≥3天需病历)/事假/婚假/产假/陪产假/丧假/调休
- FR-3.2 年假阶梯核算：入职满1年起算、按自然年或入职周年两种模式（6.1入职分界规则）
- FR-3.3 年假清零延期审批规则：未休年假按制度年度清零，支持延期书面审批（最长延至次年Q2末）
- FR-3.4 调休有效期规则：加班产生的调休自动计算有效期，过期前14天钉钉预警
- FR-3.5 预支假期权限控制：试用期不可预支年假，转正员工最多预支5天且需二级审批
- FR-3.6 特殊考勤豁免名单管理：高管/外勤/特殊岗位免打卡名单需书面审批备案后方可豁免

### FR-4：薪酬核算引擎 (Payroll Engine)
- FR-4.1 基础薪酬计算：岗位薪级×出勤比例（计薪日21.75/当月自然日两种可配置）
- FR-4.2 工龄工资：自动计算=工作年限×100元/年，封顶年限可配置（默认10年）
- FR-4.3 绩效工资：从绩效系统/钉钉文档在线表格读取分数→100分拿满绩效基数，按分数比例线性核算
- FR-4.4 试用期工资：自动按转正工资×80%核算，转正当月按日折算
- FR-4.5 加班费核算：平日1.5倍/周末2倍/法定节假日3倍；教育岗按FR-2.5豁免规则区分
- FR-4.6 缺勤扣款：事假当日全额扣；病假按80%基本工资发放（需病历）；旷工当日3倍扣；迟到早退≥3次累计扣20元
- FR-4.7 津贴补贴管理：≥30项（住房补贴/交通补贴/通讯补贴/餐补/全勤奖/高温补贴/节日补贴/外派补贴等）支持按月/按季/一次性开关
- FR-4.8 社保公积金5地差异化核算：养老8%+失业0.3%+医疗2%+公积金（可配置）+大额医疗补（8元/月西安）
- FR-4.9 个税累计预扣法：标准7级累进税率，专项附加扣除（子女教育/房贷利息/住房租金/赡养老人/继续教育/3岁以下婴幼儿照护）自动读取
- FR-4.10 工资汇总表多维度输出：按部门/按岗位/按薪级/按子机构4种汇总，自动生成银行批量代发明细（工行/建行/农行3模板）
- FR-4.11 环比异常检测：单员工薪酬环比波动≥±20%自动标记异常，附详细差异说明
- FR-4.12 教育板块独立薪酬包：教育机构独立薪酬口径支持与总部并行核算，单独出表

### FR-5：审批流自动化与集成
- FR-5.1 审批矩阵可配置：二级审批（直属上级→部门负责人）/三级审批（+分管副总）/四级审批（+财务/董事长）
- FR-5.2 审批阈值可配置：薪酬支付≤1000/2000双档可配置（默认统一2000元档避免冲突）
- FR-5.3 考勤异常审批自动发起：补卡/请假/加班/调休/旷工确认 → 钉钉OA审批自动创建
- FR-5.4 薪酬发放审批自动发起：工资表生成后自动按审批矩阵流转，审批通过自动推送财务接口
- FR-5.5 延期/豁免/特殊处理审批：所有"非标准"操作（年假延期/预支/特殊考勤豁免）统一走书面审批+留痕
- FR-5.6 SLA时效监控：D-3 18:00前异常闭环率≥95%；D-2 18:00前薪酬初算；D-1 12:00前员工确认率≥95%；D日 09:00财务代发

### FR-6：员工自助服务端
- FR-6.1 钉钉工作台微应用入口：工资条/考勤记录/假期余额/调休余额/工龄查询
- FR-6.2 月度考勤一键确认：D-2生成考勤确认单，支持员工在线确认/异议申诉
- FR-6.3 工资条推送：D-1 自动推送至钉钉消息，支持PDF导出/数字签名/防截图水印
- FR-6.4 申诉工单：考勤/工资异议→自动创建工单→HR处理时效SLA（24小时内回复）
- FR-6.5 制度查询AI助手：嵌入人资专项Agent回答"年假怎么算/加班几倍工资/社保基数多少"等制度问题，引用制度原文RAG回答

### FR-7：异常检测与合规审计
- FR-7.1 数据完整性检测：打卡缺失率/假期数据缺失/社保基数为0/银行卡号为空 自动报警
- FR-7.2 核算逻辑一致性检测：同一薪级不同员工计算逻辑比对，识别遗漏
- FR-7.3 规则版本管理：每一条规则变更有版本号、变更原因、变更人、审批记录
- FR-7.4 操作日志全留痕：所有人工修改数据/豁免/延期操作自动记录操作人、时间、IP、审批单号
- FR-7.5 合规审计报告自动生成：月度/季度/年度导出审计报告PDF，附全部规则清单与执行记录

### FR-8：AI人资专项Agent
- FR-8.1 制度问答能力：基于RAG检索403+条规则与制度原文，每条回答附来源条款
- FR-8.2 薪酬测算能力：员工自行模拟"请假5天对本月工资影响""加班10小时工资增加多少"
- FR-8.3 异常自动定位：薪酬核算结果异常自动出具差异分析报告（文字+数据表格）
- FR-8.4 月度自动汇报：每月D+3自动生成本月人资运营报告（考勤异常率/薪酬波动/假期消耗/加班统计）
- FR-8.5 预测与预警：预测下月人工成本/年假清零预警/调休过期预警/社保基数调整预警
- FR-8.6 钉钉群聊自动值班：人事行政工作群制度咨询自动回复，非标准问题自动转工单给HR

### FR-9：钉钉文档与知识库集成
- FR-9.1 制度文档钉盘统一归档：考勤管理制度/人资制度/薪酬制度/审批矩阵 钉盘知识库唯一真源
- FR-9.2 钉钉在线表格作为数据中转：考勤异常清单/工资确认单/绩效分数表 支持HR与钉钉平台双向同步
- FR-9.3 AI听记会议纪要自动入知识库：人事行政专项会议录音→自动转写→自动提取决策点→更新规则引擎待审批

### FR-10：GitHub 研发集成与CI/CD
- FR-10.1 规则引擎代码GitHub托管：每条规则变更走 Pull Request + 2人Code Review
- FR-10.2 自动化测试CI：每次变更触发403+条规则的单元测试+集成测试+回归测试
- FR-10.3 灰度发布：新版本规则先对1个部门试运行7天，无异常再全量推广
- FR-10.4 版本可回滚：任何版本问题支持一键回滚至上个稳定版本

## Non-Functional Requirements
- **NFR-1（性能）**：单公司≤500人规模，月度全量核算耗时≤10分钟；≥1000人耗时≤30分钟
- **NFR-2（准确率）**：规则引擎逻辑准确率≥99.9%；薪酬核算与人工核算偏差率≤0.01%（差异≤1元/人/月视为正常舍入误差）
- **NFR-3（可用性）**：系统年可用率≥99.95%（每月D-3至D日不可用时长≤5分钟）
- **NFR-4（安全性）**：员工敏感数据（身份证/银行卡/工资）加密存储AES-256；传输TLS 1.3；访问日志完整保留≥180天；分级权限（HR/财务/审批人/普通员工4级）
- **NFR-5（合规）**：个人信息保护法（PIPL）、数据安全法、社保法、个税法完全合规；审计报告可随时导出应对监管检查
- **NFR-6（可扩展性）**：薪级/假期/津贴/补贴/参保地/审批节点均支持热配置，无需代码变更即可上线
- **NFR-7（可维护性）**：规则引擎与业务代码解耦；403+条规则单元测试覆盖率≥95%；关键模块代码注释完整度≥80%
- **NFR-8（钉钉集成稳定性）**：钉钉API调用失败自动重试3次（指数退避）+ 降级熔断；钉钉推送失败自动通过短信/DING二次兜底

## Constraints
- **Technical**：必须深度对接钉钉开放平台（通讯录/考勤/OA审批/文档/表格/知识库/机器人/AI能力），不得脱离钉钉另建独立入口；后端采用Node.js 20 LTS，前端钉钉小程序+Vue3；规则引擎优先使用JSON Schema+计算图，避免硬编码业务规则
- **Business**：6个月内完成全量上线（分6期）；首期必须覆盖80%核心规则（322/403条）；上线并行期1个月，人工核算与系统核算双轨比对
- **Compliance**：数据不出企业内网；银行代发接口需与企业财务系统/代发银行签署三方安全协议
- **Dependencies**：钉钉企业版/专业版API权限（需开通通讯录读写/考勤读写/审批实例读写/文档读写能力）；企业GitHub仓库；企业内部LLM或API Key；钉钉AI搜问/AI表格/AI听记/知识库开通

## Assumptions
1. 钉钉开放平台API提供的考勤数据、审批数据、通讯录数据是当前企业的权威真源，不存在上游数据造假
2. 所有制度文件的最终解释权归集团HR分管副总以上高管层，规则引擎严格按书面审批通过的规则执行，不做任何"超权判断"
3. 员工自愿接受薪酬确认钉钉推送方式，无需纸质签字（可随时下载加盖电子章的版本）
4. 企业内网可稳定访问钉钉开放平台；月度核算高峰期间（D-3 18:00-22:00，D-2 10:00-18:00）网络与服务器资源充足
5. 现有6月/7月真实薪酬表与考勤数据足以作为训练与验证数据集
6. 规则的变更流程由制度委员会（≥HR分管副总+财务总监+HR专员3人签字）审批通过后，由技术团队在T+3工作日内完成上线

## Acceptance Criteria

### AC-1：主数据中心自动与钉钉双向同步
- **Given**：钉钉通讯录新增一名员工（含部门/岗位/直属上级/入职日期/薪级）
- **When**：主数据中心每小时轮询钉钉通讯录API（或接通讯录变更事件）
- **Then**：10分钟内员工主数据档案自动创建，员工ID与钉钉userId绑定，工龄工资/试用期工资自动预计算，准确率100%
- **Verification**：`programmatic`
- **Notes**：反向修改主数据中心→10分钟内回写钉钉通讯录（受权限控制）

### AC-2：月度考勤D-3自动采集与异常识别
- **Given**：当月考勤周期结束（上月26日至本月25日，或自然月，可配置）
- **When**：D-3日23:59系统自动触发考勤采集任务
- **Then**：全公司考勤打卡数据100%拉取完成，16类考勤异常识别准确率≥99%，钉钉机器人异常派单覆盖率100%
- **Verification**：`programmatic`
- **Notes**：比对人工考勤表，抽查50名员工异常数误差≤0

### AC-3：教育板块加班规则自动区分且正确
- **Given**：教育板块岗位员工平日加班2小时；非教育板块岗位员工平日加班2小时
- **When**：薪酬核算引擎自动识别教育岗岗位标签
- **Then**：教育岗按制度规则执行（豁免或按规定折扣）；非教育岗按1.5倍核算；二者不混淆
- **Verification**：`programmatic`
- **Notes**：比对6/7月真实工资表教育板块加班工资总额误差率≤0.5%

### AC-4：薪酬初算D-2完成，准确率99.9%
- **Given**：D-2 14:00考勤异常已闭环≥98%，主数据完整，绩效分数已导入
- **When**：一键触发薪酬核算
- **Then**：10分钟内完成所有员工薪酬明细计算，基础工资+绩效+工龄+加班+缺勤+社保+公积金+个税全部逻辑准确；与人工核算结果比对，差异员工数≤0.1%（即1000人≤1人差异）
- **Verification**：`programmatic`
- **Notes**：差异值≤1元视为正常舍入误差，不计入

### AC-5：5地社保公积金差异化正确核算
- **Given**：西安/天水/白银/平凉/兰州5地各抽1名员工，参保基数、公积金比例、大额医疗补各不相同
- **When**：系统核算当月社保公积金个人部分
- **Then**：每地每项社保比例、基数上下限、大额医疗补金额与当地人社局最新标准完全一致（8月西安医保5132验证）
- **Verification**：`programmatic`

### AC-6：薪酬波动≥±20%自动生成异常审批
- **Given**：某员工本月工资与上月相比变化≥20%（如请假10天或大额加班费）
- **When**：薪酬核算完成后异常检测引擎运行
- **Then**：自动生成"薪酬异常说明"审批单至直属上级→HR→分管副总三级审批，审批完成后方可进入工资发放
- **Verification**：`programmatic`

### AC-7：D-1工资条钉钉推送+自助确认率≥95%
- **Given**：工资表已审批通过
- **When**：D-1 09:00推送任务执行
- **Then**：每位员工钉钉消息收到加密工资条，支持PDF导出/数字签名；24小时内自助确认率≥95%，未确认员工自动DING提醒
- **Verification**：`programmatic` + `human-judgment`

### AC-8：人资Agent制度问答准确率≥95%
- **Given**：从403条规则中随机抽取50道自然语言问题（如"我去年的年假今年还能休吗""产假多少天""社保个人扣多少"）
- **When**：向钉钉端人资Agent提问
- **Then**：≥95%的问题能正确回答，且每条回答附带引用的制度条款编号/制度文件名/生效日期，可溯源
- **Verification**：`human-judgment`
- **Notes**：错误的回答要在48小时内由HR更新知识库并重新训练

### AC-9：规则变更走GitHub PR+CI自动化测试
- **Given**：HR提出规则变更（如"工龄工资从100元/年调整为150元/年"）
- **When**：技术团队提交PR修改规则配置
- **Then**：GitHub Actions自动运行403+条单元测试+集成测试+回归测试，通过率100%方可合并；合并后自动灰度发布至测试环境
- **Verification**：`programmatic`

### AC-10：合规审计报告一键导出

- **When**：HR管理员点击"导出审计报告"
- **Then**：生成含以下内容的PDF：①员工花名册及异动统计 ②考勤异常明细与闭环率 ③假期消耗与清零情况 ④薪酬发放汇总表 ⑤社保公积金缴纳明细 ⑥规则版本变更记录 ⑦人工操作日志 ⑧审批流完成率与SLA达标率
- **Verification**：`human-judgment`

### AC-11：系统D-3至D日SLA完全达标
- **Given**：正常核算月，无重大钉钉API故障
- **When**：执行完整月度核算全流程
- **Then**：①D-3 18:00 考勤异常闭环率≥95% ②D-2 18:00 薪酬初算100%完成 ③D-1 12:00 员工确认率≥95% ④D日 09:00 工资表自动推送财务代发接口
- **Verification**：`programmatic`

### AC-12：HR月度核算总人时从80降至≤2
